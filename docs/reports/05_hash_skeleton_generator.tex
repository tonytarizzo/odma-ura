\section{Research philosophy at the current frontier}

The strongest empirical lead remains the global $L=1$ codebook, not the sectioned outer-code route. The desired method
should therefore remove the exponential implementation cost without unnecessarily replacing that broad family by one
specific tree or parity construction. This is a methodological principle rather than a claim that restrictions can
always be avoided:
\begin{enumerate}
 \item begin from the unrestricted explicit object whose behaviour is understood;
 \item identify redundancy or invariance empirically and algebraically;
 \item impose the smallest tractable structure that removes the bottleneck;
 \item compare that restriction against the broader parent family before adding another;
 \item distinguish compact forward generation from scalable inverse decoding.
\end{enumerate}
If a restriction is eventually necessary, it should enter because an experiment or proof justifies it, not because a
named construction makes implementation convenient.

\section{Why counting available supports is insufficient}

There are $\binom ns$ unsigned size-$s$ masks. For $n=256$,
\[
 \log_2\binom{256}{21}\gtrsim100,
 \qquad
 \log_2\binom{256}{24}\approx111.36.
\]
Thus support labels alone can in principle distinguish $2^{100}$ messages around $s=21$--24. This does not solve the
communication problem. A useful family must also have balanced rows, controlled pair intersections and signed
correlations, separation between sums of $K_a$ columns, and a receiver that can propose likely messages without
enumerating all $2^B$ labels.

Job 027 shows this distinction directly. All 4096 support/sign patterns remain distinct through $s=4$, but performance
degrades much earlier. As $s$ falls from 32 to 8, sampled correlation q99.9 rises from about 0.256 to 0.479 and the
fraction of rows occupied by a $K_a=30$ active set falls from 0.982 to 0.613. At $s=1$, the namespace itself finally
collapses: only 256 supports and 512 real signed directions exist.

The conservative procedural target $s=24$ is therefore a rate/geometry starting point, not a $B=100$ feasibility
claim. $s=21$ is an aggressive combinatorial boundary. Neither number supplies an inverse algorithm.

\section{Generator--proposer specification}

Write a message as $w\in\{0,1\}^B$. A procedural compact encoder replaces stored columns by
\[
 S_\theta(w)=\{\rho_0(w),\ldots,\rho_{s-1}(w)\},
\]
\[
 \phi_\theta(w)=\sum_{t=0}^{s-1}\alpha_t(w)e_{\rho_t(w)},
 \qquad \sum_t|\alpha_t(w)|^2=1.
\]
The payload bits are binary inputs to the generator; the transmitted nonzero values $\alpha_t$ may be real or complex.

Forward generation is only half of a scalable code:
\[
 \operatorname{codeword}_\theta(w)\longrightarrow\phi_\theta(w),
\]
\[
 \operatorname{pro}(y)\longrightarrow\mathcal C(y),
 \qquad |\mathcal C(y)|\ll2^B,
\]
where the candidate list should contain the active messages with high recall. Distinct generated descriptions provide
isolated-message injectivity only. The inverse search must work in noise and in a multiuser superposition; otherwise
the receiver still tries $2^B$ messages.

The desired tests are therefore not only PUPE. They include proposal recall, candidate-list size, runtime/memory,
unit-energy error, row balance, support repetition, pair overlap/correlation, active-set Gram spectra, $K$-sum
separation, and complete-message recovery after the proposer.

\section{Master table/bin hash skeleton}

Let $n=TR$: divide resources into $T$ disjoint tables with $R$ rows each. Choose one row in every table:
\[
 \rho_t(w)=tR+h_t(w),\qquad h_t(w)\in\{0,\ldots,R-1\}.
\]
With phase/sign decoration $\xi_t(w)$,
\[
 \boxed{g(w)=\frac{1}{\sqrt T}\sum_{t=0}^{T-1}\xi_t(w)e_{tR+h_t(w)}.}
\]
If $|\xi_t(w)|=1$, then $\|g(w)\|_2^2=1$ exactly. Two codewords have inner product
\[
 \langle g(w),g(v)\rangle=\frac{1}{T}\sum_{t=0}^{T-1}
 \mathbf 1\{h_t(w)=h_t(v)\}\xi_t(w)^*\xi_t(v).
\]
Hashes control overlap and balance; phases can cancel the signed sum. The restriction changes the support family from all
$\binom nT$ masks to $R^T$ one-per-table masks. Its rate condition is
\[
 B\le T\log_2R=T\log_2(n/T).
\]
Expected pair overlap under uniform table choices is $T/R=T^2/n$, matching the first-order value for two independent
size-$T$ supports. Tail geometry can still differ, so it must be measured against arbitrary sparse supports.

\section{Binary affine hash family}

When $R=2^r$, let
\[
 h_t(w)=A_tw\oplus b_t,\qquad
 A_t\in\F_2^{r\times B},\quad b_t\in\F_2^r.
\]
$\F_2$ means arithmetic on bits: addition is XOR. Full row rank of each $A_t$ makes every table exactly balanced. Full
column rank of the stacked matrix
\[
 A_{\rm stack}=[A_0^T\ \cdots\ A_{T-1}^T]^T\in\F_2^{Tr\times B}
\]
makes the complete hash tuple injective, because
\[
 A_{\rm stack}w=A_{\rm stack}v\Longrightarrow A_{\rm stack}(w\oplus v)=0
 \Longrightarrow w=v.
\]
For difference $d=w\oplus v$, the two supports collide in table $t$ exactly when $A_td=0$. At small $B$, enumerating
all nonzero $d$ gives the exact overlap spectrum. Job 028 selects the best of 128 random full-rank banks by worst and
tail collision counts.

The matrices $A_t,b_t$ are fixed discrete design parameters, not gradient-trained. They can be randomly sampled,
searched, or designed algebraically. Keeping their rank constraints exact is more important than forcing them into a
continuous relaxation. The phase/amplitude rule and downstream decoder can still be learned.

\section{Connection back to the explicit factorisation}

At $B=14$, every generated support can be materialised without changing D0/D1. Define
\[
 (P_t)_{jm}=\mathbf 1\{j=h_t(w_m)\},\qquad
 D_t=\diag(\alpha_{t0},\ldots,\alpha_{t,M-1}).
\]
Then
\[
 \Phi=
 \begin{bmatrix}P_0D_0\\P_1D_1\\\vdots\\P_{T-1}D_{T-1}\end{bmatrix}
 \in\R^{TR\times2^B},
 \qquad
 \Phi_{tR+j,m}=\alpha_{tm}\mathbf 1\{j=h_t(w_m)\}.
\]
This is an $L=1$ global matrix with generated support, not the section-count representation of Report 4. D0/D1 retain
their unchanged residual and adjoint operations. The small-$B$ experiment therefore asks a clean question: does this
support restriction damage the promising explicit landscape before a new proposer is built?

\section{What is learnable without breaking the skeleton}

If $S\in\{0,1\}^{n\times M}$ is the fixed materialised support and $V$ contains trainable amplitudes,
\[
 \Phi=S\odot V,
 \qquad
 \frac{\partial\mathcal L}{\partial V}=S\odot\frac{\partial\mathcal L}{\partial\Phi}.
\]
The mask makes all off-support gradients zero. Projection after every optimiser step,
\[
 \phi_m\leftarrow\frac{\phi_m}{\|\phi_m\|_2},
\]
guarantees unit power for the final learned codebook. Dense controls use the same projection.

The original certification stores amplitudes per message. To remove that second exponential object, choose one
invertible $Q\in\F_2^{B\times B}$ and let $P_J$ be its first $J$ rows. Define
\[
 u_J(w)=P_Jw\in\F_2^J,\qquad V\in\R^{T\times2^J},\qquad
 \alpha_J(w)=\frac{V_{:,u_J(w)}}{\|V_{:,u_J(w)}\|_2}.
\]
The transmitted column is
\[
 \boxed{\phi_J(w)=\sum_{t=0}^{T-1}\alpha_{J,t}(w)e_{tR+h_t(w)}},\qquad
 \|\phi_J(w)\|_2^2=1.
\]
Thus the saved generator contains $A,b,P_J,V$ and needs $T2^J$ amplitude values rather than $T2^B$. At $J=0$, all
messages share one learned table profile. At $J=B$, $P_B=Q$ is bijective, so $V$ assigns an arbitrary amplitude vector
to every message and recovers the old model class. Because the $P_J$ are prefixes, any $J$-bit bank can be copied into
the two halves of a $(J+1)$-bit bank; hence these classes are genuinely nested.

The support maps $A,b$ and label map $P_J$ remain fixed discrete designs. In a learned run, gradients from every message
with label $u$ accumulate into $V_{:,u}$ through the column normalisation; in a fixed run, $V$ is a buffer and only the
decoder trains. This gives a paired test of amplitude adaptation without changing support. It also guarantees deployment
power for messages never sampled in training. A selected-message $B=100,n=256,T=64,J=8$ regression test generates
columns without allocating a $2^{100}$ object. Current D0/D1 still allocate such a message axis, so forward scalability
does not establish inverse scalability.

\section{Jobs 028--030 and their causal decision gates}

Job 028 fixes $B=14,n=256$, $T\in\{16,32\}$, D0/D1, and two seeds. It compares:
\begin{enumerate}
 \item iid arbitrary sparse support;
 \item balanced random one-per-table support;
 \item random affine binary hashes;
 \item collision-spectrum-selected affine hashes;
 \item dense context.
\end{enumerate}
The sequence isolates the cost of tables, then linear/XOR structure, then offline hash selection. Fixed Gaussian
amplitudes are paired across sparse families and normalised exactly.

Job 029 jointly trains amplitudes and the chosen decoder for 120 epochs on dense, iid sparse, and selected-hash supports
at $T=16,32$. It records pre/post geometry and full loss curves. This separates a fixed-amplitude or under-training floor
from a limitation of the support skeleton. It is still a small-$B$ model-class test because the learned amplitudes and
D0/D1 states are message-indexed. All 20 rows returned. Selected hash and iid sparse differ by less than 0.011 PUPE in
every matched aggregate, so no important hash penalty is visible at current precision. Fixed and joint runs used
different training budgets, so they do not isolate the value of amplitude learning; job 030 makes that comparison fair.

Job 030 fixes the selected $T=32$ hash and sweeps $J\in\{0,2,4,8,14\}$ at $B=14,n=256$. Every $J$ has a fixed-$V$
row and a matched jointly learned-$V$ row for D0/D1 and two seeds. Fixed equal-amplitude and Rademacher controls are
included. All rows have a 120-epoch ceiling, stop after five validation epochs without improvement, and restore the
best checkpoint. This isolates amplitude model-class loss before candidate proposal is introduced.

The decision order is deliberately conservative:
\begin{enumerate}
 \item if balanced tables are materially worse than iid sparse, reject or revise the table restriction;
 \item if tables survive but affine hashes fail, retain the skeleton and change the generator family;
 \item if selected hashes match iid support, find the smallest $J$ that matches the $J=B$ amplitude endpoint;
 \item only then introduce a proposer and measure proposal recall separately from final PUPE;
 \item keep exact small-$B$ materialisation as a permanent regression reference.
\end{enumerate}

\evidence{Local tests verify exact support size, unit energy, $\F_2$ ranks, support injectivity, nested amplitude classes,
the unrestricted $J=B$ endpoint, gradients only into $V$, and finite fixed/joint D0/D1 paths. A 12-run $B=8$ mini-grid
improved held-out loss in every tested case. No job-030 HPC performance result is recorded yet.}

\section{Current claim and boundary}

The project has evidence that a broad sparse-global $L=1$ family can be much sparser than dense without reproducing the
ODMA penalty. It has a compact candidate support skeleton whose forward map is injective and unit-energy by
construction. It now has a compact nested amplitude family, but no HPC evidence yet showing which $J$ preserves the
unrestricted endpoint, and no high-recall sub-exhaustive inverse proposer for noisy multiuser sums.

That boundary is the research opportunity. The next successful design should look like the favourable explicit global
model to the channel, but like a compact generator and searchable algebra to the implementation. This preserves the
general direction without mistaking storage compression, isolated-message invertibility, or local section decoding for
complete scalable URA.
