\section{Purpose}

The explicit experiments used a different construction routine for each codebook. The framework replaced those special
cases by one factorisation, allowing representation, encoder learning, and decoder learning to be compared without
changing the outer experiment contract. It also clarified two different meanings of ``implicit'': avoiding a stored
$n\times M$ matrix is useful, but it does not remove an $M=2^B$ decoder state.

\section{Full global construction and shapes}

Let $M=2^B$ and let $L$ be the number of additive components. Component $\ell$ has:
\[
 R_{\ell,q}\in\C^{n\times d_\ell},\quad q=0,\ldots,Q_\ell-1,
 \qquad C_\ell\in\C^{d_\ell\times V_\ell}.
\]
Define the complete product bank
\[
 B_\ell=[R_{\ell,0}C_\ell\mid\cdots\mid R_{\ell,Q_\ell-1}C_\ell]
 \in\C^{n\times(Q_\ell V_\ell)}.
\]
A sparse selector $U_\ell\in\{0,1\}^{Q_\ell V_\ell\times N_\ell}$ retains $N_\ell$ legal local atoms. A lookup
$T_\ell\in\{0,1\}^{N_\ell\times M}$ has one nonzero per column and maps every global message to one local atom. The
global codebook is
\[
 \boxed{\Phi=\sum_{\ell=1}^L B_\ell U_\ell T_\ell\in\C^{n\times M}.}
\]

For global counts $a\in\R^M$, the noiseless signal is
\[
 y=\Phi a=\sum_\ell B_\ell U_\ell s_\ell,
 \qquad s_\ell=T_\ell a\in\R^{N_\ell}.
\]
$s_\ell$ aggregates every global message that uses the same local atom. This is the core many-to-one compression, but
the explicit backend still needs the length-$M$ mapping $T_\ell$ and a length-$M$ output to distinguish messages.

\subsection{Column-level interpretation}

If message $m$ maps to local atom $i_\ell(m)$, and that atom represents pair $(q_\ell(m),v_\ell(m))$, then
\[
 \phi_m=\sum_{\ell=1}^LR_{\ell,q_\ell(m)}c_{\ell,v_\ell(m)}.
\]
This can represent a dense global codebook, ODMA placements, shared product alphabets, restricted valid pairs, multiple
section contributions, and fixed or learned local matrices. Representability is not the same as compact scalability:
an arbitrary $T_\ell$ contains $M$ choices.

\section{How implementation avoids materialising the global matrix}

The implemented component stores integer arrays describing the $N_\ell$ legal atoms and a length-$M$
\texttt{msg\_to\_atom} lookup. The forward path performs
\[
 a\xrightarrow{T_\ell}s_\ell
 \xrightarrow{U_\ell}\text{coefficients on }(q,v)
 \xrightarrow{C_\ell}\text{one local vector per }q
 \xrightarrow{R_{\ell,q}} y_\ell,
\]
then sums $y=\sum_\ell y_\ell$. The adjoint reverses these operations:
\[
 r\xrightarrow{R_{\ell,q}^H}r_{\ell,q}
 \xrightarrow{C_\ell^H}\text{scores on }(q,v)
 \xrightarrow{U_\ell^H}\text{local atom scores}
 \xrightarrow{T_\ell^H}\Phi_\ell^Hr.
\]
Thus normal training uses memory proportional to factors plus $M$, rather than $nM$. Selected columns or the entire
matrix can still be materialised for small-system diagnostics.

\subsection{Gradient flow}

For loss $\mathcal L(y)$ and upstream vector $g_y=\partial\mathcal L/\partial y$, automatic differentiation follows the
same adjoints. For example, with $Z_{\ell,q}=C_\ell X_{\ell,q}$ and $y_\ell=\sum_qR_{\ell,q}Z_{\ell,q}$,
\[
 \frac{\partial\mathcal L}{\partial Z_{\ell,q}}=R_{\ell,q}^Hg_y,
 \qquad
 \frac{\partial\mathcal L}{\partial C_\ell}=\sum_q(R_{\ell,q}^Hg_y)X_{\ell,q}^H.
\]
The gradient with respect to counts is $\partial\mathcal L/\partial a=\Phi^Hg_y$. Fixed integer selectors $U,T$ receive
no gradient; learning them requires a discrete search or a separate relaxation. Learning $C$ or continuous $R$ does not.

\section{D0: exact data consistency, learned scalar denoising}

After matched channel combining, initialise $a^0=0\in\R^{P\times M}$ for batch size $P$. At layer $t$,
\[
 r^t=y-\Phi a^t,\qquad g^t=\Re\{\Phi^Hr^t\},\qquad
 u^t=a^t+\eta_tg^t,
\]
where $\eta_t>0$ is scaled by an implicit estimate of $\|\Phi\|_2^2$. With known $K_a$, D0 uses
$\rho=K_a/M$ and produces calibrated support logits
\[
 \lambda_j^t=\operatorname{clip}\!\left[
 \gamma_t\frac{u_j^t-1/2}{\tau_t}+\beta_t\log\frac{\rho}{1-\rho}+b_t,-30,30\right].
\]
The soft proposal is $\widetilde a^t\propto\sigma(\lambda^t)$, normalised so $\one^T\widetilde a^t=K_a$, and damping
forms $a^{t+1}$. Only the final evaluation output is projected to nonnegative integer counts.

The exact $\Phi/\Phi^H$ pair preserves physical data consistency. Learned parameters calibrate evidence, prior strength,
temperature, step size, and damping; there is no learned dense message-to-message matrix. Gradients flow through every
unrolled layer to the decoder scalars and any learnable encoder matrices.

\section{D1: nonlocal factor context}

D1 starts with the identical D0 map and adds a learned proximal correction. For a single product component it labels
each message by its pattern $q_j$ and local value $v_j$. Per-message features include $u_j^t,a_j^t,g_j^t$, base logit,
pattern mass, residual scale, noise scale, and prior logit. Slot attention pools context:

\begin{itemize}
 \item within messages sharing $q$;
 \item across patterns sharing $v$;
 \item globally across all messages.
\end{itemize}

A small correction network adds $\Delta_j^t$ to the D0 logit. It is zero-initialised, so before training D1 is exactly
D0. This construction is linear rather than quadratic in $M$ for fixed slot count, but it remains $M$-indexed and is
several times more expensive than D0.

\section{Validation before performance claims}

The framework passed exact or numerical checks for implicit versus materialised forward maps, adjoint identities,
selected-column construction, legacy ODMA representation, reduced sectioned CCS representation, and tiny exact count
ML. The normal $B=14,M=16384$ training path completed without an $n\times M$ matrix. These checks establish that the
factor operations implement the intended small-$B$ algebra; they do not validate an arbitrary decoder or establish
paper-faithful CCS-AMP equivalence.

\section{Jobs 021--022: what was learned}

The controlled bank used $L=1$, $U=T=I$, and $d=n$. It compared dense, shared product, independently sparse-global, and
four-mask ODMA encoders at four $(B,n)$ geometries: $(12,128)$, $(12,256)$, $(14,128)$, and $(14,256)$.

Across all evaluation cells, D0 improved over matched filtering by about $0.004$ PUPE on average. D1's improvement was
about $0.042$ at 8/12 dB, but D1 also helped dense codebooks; the experiment therefore supports nonlocal learned context,
not a uniquely product-factor gain. Product sharing was competitive but slightly worse than dense on average, and
learning $C$ was mixed across geometries. Median D1 runtime was $5.2$ times D0.

The most consequential result was morphological. Sparse-global and ODMA both used 25\% nonzeros per column, but
sparse-global gave each message an independently sampled support. ODMA reused only four masks. Sparse-global row-energy
coefficient of variation was $0.023$--$0.053$; ODMA's was $0.839$--$0.875$, with about 30\% of rows unused. Sparse-global
was within $0.016$ PUPE of dense in every geometry and essentially tied at $n=256$.

\evidence{Measured finite experiment. It shows that this ODMA support reuse is harmful under the tested decoder; it does
not show that sparsity is universally harmless or that sparse-global storage is scalable.}

\section{Scalability boundary}

Even without a stored $\Phi$, the explicit framework keeps $T_\ell$ and $a^t$ indexed by all $M$ messages. Going from
$B=14$ to $B=100$ multiplies that dimension from $16{,}384$ to approximately $1.27\times10^{30}$. Factorised matrix
arithmetic alone cannot cross this boundary. The next stage must generate a message's local choices procedurally and
decode from local states without ever expanding them back to every global message.
