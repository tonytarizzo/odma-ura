# One final magnitude query on the flat GMAC curves

The separate balanced K100 comparison motivates testing whether a single wide query also helps on the flat encoder. Use every K50 and K100 geometry and energy already declared in [the energy-curve design](curve_design.md). This is a secondary paired comparison with the registered count-growth endpoint. The three primary curves, comparisons and inference retain their original definitions.

Start from the complete DEC-35 bank and its fitted cancellation counts. When those counts sum to K−1, subtract their waveforms from the original observation, rank all patterns by the sum of absolute residual samples, and query the top pattern with ordinary CRC-aided SCL4096. Use the signed samples and known noise variance for the LLRs. Include all returned complete IDs, including IDs already in the bank. If the bank grows, refit its counts and then apply terminal support completion. With an unchanged bank, repeat completion on the original fitted counts. At any other fitted cardinality return the complete baseline action. A slot filled by the baseline's terminal readout is deliberately absent from the fitted count used for this trigger. The existing `framework.polar_terminal_query.finish` implements this policy. Its only inputs from the prefix metadata are the complete flag, cancellation counts and bank. It also receives the original complete baseline action for its no-query branch.

Charge the shared cold receiver and geometry once per complete endpoint, plus the additional call to `finish`, including the guard, full scan, SCL provider construction, search, optional refit and readout. Record each case's trigger, returned multiset, costs, actual ordered CRC-valid IDs and metrics, new IDs, fit and completion trace, and the hash of the actual float64 LLR vector where queried. The observer retains the actual LLR reference while the receiver is timed. Hashing, truth scoring and serialization occur afterwards. The receiver gets no labels. Each query is charged even if an earlier stage visited the same pattern. The list width changes to 4096.

Report both receivers' transmitted-user list PUPE, count-PUPE, false copies, output sizes, frame wins/ties/losses, trigger and SCL4096 totals, and wall time at each measured energy. Include paired pointwise 95% intervals for list- and count-PUPE savings and false copies per user saved. For each load and both loss measures, compute the 5% crossing on the original grid and the paired baseline-minus-terminal dB difference. Resample complete geometries, keeping both methods and all energies together, with the same 10,000 weights and conservative censoring rules as the primary study. These secondary percentile intervals are descriptive. A favorable individual energy or triggered subset does not establish a positive energy difference. Report unbounded results when the grid cannot resolve the crossing.
