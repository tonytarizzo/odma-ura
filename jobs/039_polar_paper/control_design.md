# Matched-search controls and residual intervention

The held-out panel contains frame zero on each of 128 new geometry seeds, 933001–933128. All arms use the flat original B100 encoder, 13 pattern bits, 87 payload bits, CRC16, 512 chips on a 30,000-coordinate Gaussian channel, 100 independent uniform full messages, and 0.5 dB. K and noise are known. Each geometry, transmitted multiset and noise realization are shared across arms. Truth is available only to the evaluation functions. The declared receiver comparisons and the residual intervention share these 128 frames.

## Complete receiver and search controls

Run the registered DEC-35 count-growth option cold with native repetition, memoization, terminal completion and conditional fourth sweep. Record the complete count action, bank, native and rollback work, ordered continuation queries, cache hits, fits, and elapsed receiver time. Separately regenerate the common native-REP128 and four-by-eight rollback512 prefix with an observer that records the exact physical pattern and float64 LLR bytes at each query. Require equality to the registered run's accepted rollback action, all four batches, complete initial bank, native rounds/ID union/residual hash and call count. The observer's prefix work and memory are a receiver expense for the controls. Every standalone control is charged full geometry, this measured prefix and its own extension and terminal readout. Shared execution saves diagnostic compute. The study also charges reference execution, verification and every diagnostic replay in its own total.

Three extensions receive exactly 210 new ordinary SCL128 computations. This is twice K+5, chosen before any outcomes. All rank all patterns by descending absolute residual sums with stable tie order. At every change of counts, restart the ranking on the new raw physical residual. At a fixed state continue down the full ranking, beyond the K+5 highest scores when needed. Skip a pattern only if the same pattern and exact LLR bytes were already queried at width 128 in the common native prefix or already tried by this extension. Identical native REP128 inputs are treated as previously attempted SCL128 queries; finite tie differences between REP128 and the ordinary implementation remain possible. Requery a context seen only at rollback512 and record the overlap: neither width contains the other list in general. Across *different* pattern IDs an exact byte match in the SCL128 payload cache restores the cached payload list on the current pattern at zero additional SCL calls. Every new ranked opportunity, skip, cache hit, actual call, list, count change, and all full search and terminal times are recorded. If the ranking exhausts, return the actual achievable work and flag the frame. No filler calls count against the budget.

- **Conventional extra search** uses the first CRC-valid word and cancels one copy immediately when its complete ID is unreported and a slot is free. A reported top ID does not promote the second ID to hard cancellation, in agreement with the native rule. All CRC-valid IDs enter the common terminal bank. Record whenever another unreported ID accompanies a top ID already accepted. Hard SIC reconstructs only the active waveform sum and divides the raw residual numerator by noise plus max(K minus accepted copies minus one, zero)/n; no accepted word or same-pattern companion is restored before a query. This arm constructs a count bank only if the terminal completion needs one. Its initial state is the common rollback action.
- **Addition-only** runs the count-bank fit on the initial bank and after each new complete ID, with the ordinary add gain and deterministic tie order. It can add repeated copies, with no drop or swap.
- **Reversible** uses the original CountBank add/drop/swap fit at the same events. This fixed-work policy is a controlled DEC-35 variant. The registered receiver retains its own sweep order and stopping rule.

Each extension performs identical terminal support completion on its own counts and discovered bank. The factual discovery lists can differ as a consequence of earlier moves. A fixed-work claim requires complete 210-paid-call endpoints for all arms on all 128 frames. Store partial-coverage comparisons and excluded seeds if this gate fails. Report paired missed-copy differences, false copies, misses under list membership, frame wins/ties/losses, largest-frame sensitivity, two-sided sign test and descriptive paired-frame percentile intervals. Counts refer to whole patterns and payloads and preserve multiplicity.

The conventional search also saves an endpoint after exactly the registered receiver's actual number of continuation SCL128 calls per frame, and extends to bracket the measured wall time of the actual complete registered decoder. Use the same geometry charge on both sides. At zero and after each completed *paid* call, measure the conventional terminal completion without feeding it back into discovery. A standalone endpoint charges that completion once plus cumulative setup, ranking, skipped/cached inputs, association, update and bookkeeping. All other endpoint probes are charged to the experiment only. Save the last completed endpoint within the limit and the first beyond it. Actual wall allowance comes from the reference measurement and is available solely for the matched experiment. If common initialization already exceeds the target, the below-budget endpoint is absent; if the state exhausts before an overshoot, retain that fact. Compare both neighbors, matched calls and 210-call controls separately. Measured runtimes vary with hardware. A wall-time advantage requires both neighbors everywhere and lower total misses versus both on this fixed panel. Additional accuracy claims require the direction and frame concentration to be reported along with costs.

## Controlled residual intervention

Use every logical continuation query of the actual registered receiver, including queries before the fourth sweep and queries that hit its cache. For each physical count state reached by a refit, freeze the numerator at the immediately preceding distinct physical count state. The first predecessor is the common rollback action. An opportunity is any actual query following a count change, whether or not that change touched its coordinates, changed an ordered list, or recovered a true word. Unchanged initial states provide exact negative controls. Both numerator choices use the same observed pattern and order, same ordinary SCL128, and same scalar variance from the live pre-query outside count. Each branch starts with a cold memo. Refit each branch's own discovered bank when that branch receives new IDs and apply the normal terminal completion. Verify every live list, physical LLR digest, new-ID set, count transition and final output against the registered trajectory. Classify transitions with any drop/swap separately from addition-only transitions; count all eligible opportunities, including equal inputs.

The frozen numerator and scheduling use the actual live count history. Its terminal count action is a controlled readout along an externally supplied schedule. Only the registered arm and complete search controls are autonomous receivers. A causal numerator effect on these query inputs can establish a change in complete-message discovery or retention on this specific schedule. Record distinct true/false discoveries per frame, both exclusive sets, retention through each branch's terminal action, and paired whole-frame count-PUPE and false copies. A capability claim requires positive net additional true discoveries, improved aggregate final counts, improvements on at least two physical frames, and a net count improvement after removing the largest gain; otherwise report the individual mechanism outcomes. A separate strong performance claim requires further evidence. Query opportunities are dependent within each frame.

The registered call runs first because its observed time and paid continuation count set two experimental endpoints. The three standalone extensions rotate order across seeds. Hardware warm-up, shared prefix replay and clock noise limit the interpretation of a per-frame time cutoff. The near-time pair brackets the first completed call to cross it; the conventional arm may incur a second setup/receiver reconstruction in the study. The 210-call reversible gain is declared only with complete coverage and positive aggregate missed-copy savings against *both* controls after removing each comparison's largest improved frame. Positive held-out results at a single operating point are local evidence.
