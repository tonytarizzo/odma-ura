# Observation used by the native pattern detector

The real BPSK signal at unit coherent channel gain has a sufficient statistic Re(y). In the circular complex observation y=x+z, the imaginary noise coordinate has variance N0/2 and is independent of every message and the real observation. It still changes the heuristic score sum |y_j| if complex magnitudes are used. Section II and the pattern ranking in the ODMA–polar paper leave a consequential implementation choice here. This sensitivity comparison is secondary to the paired real-receiver study. [Original paper](https://doi.org/10.1109/LWC.2024.3359270)

Fix the first 64 of the 256 declared seeds at each load and every declared energy. Keep the same real y, messages, n, K, rate and power. Draw one independent standard imaginary noise vector per geometry using PCG64([390274,seed,0]); reuse it across energies, scaled to the same per-quadrature variance. Run native REP-SCL128 and parallel SIC with the same remaining+5/slack, collision policy, limits and ordering as the primary native implementation. Rank each pattern by the sum of hypot(real residual, imaginary noise) on its occupied resources. Decode from real sufficient LLRs and cancel real waveforms. Bill the additional magnitude table and each complete scan. Record true list loss, count loss, false copies, actual output, calls, time and hashes. Verify against the ordinary real native entry with the imaginary vector set to zero on small inputs. The native comparison and frozen DEC-35 both see the same complex channel; DEC-35 projects to its real sufficient statistic.

Report separate thresholds for both native interpretations and DEC-35 on the same 64 independent draws per load, employing the same raw adjacent-grid and censoring rules and jointly resampling frames. Record the paired native-to-DEC35 dB differences. This experiment addresses a detector convention; neither independent implementation is the authors' source code.

The two native implementations return the same kind of accepted list. The primary native stage also records the full CRC-valid union for rollback, whereas the complex-screen standalone only records the top accepted words. Its wall time is an implementation measurement; it does not isolate the cost of the magnitude convention.
