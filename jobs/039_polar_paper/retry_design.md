On the retry slots, stable sort all previously queried changed patterns using (A) current residual absolute sum, (B) current full folded log Bayes factor, (C) B plus log of the residual-change statistic below, or (D) B plus log of its variance-only analogue. All returned complete IDs enter the same bank and the unrestricted CountBank objective/terminal first-copy completion is applied once after each fixed batch. With frozen fitted action a, r=y−Phi a and v=noise+max(h−1,0)/n. The original LLR is L=2Ar/v. For last queried residual r0 and variance v0, L−L0=2A(r−r0)/v + 2Ar0(1/v−1/v0). The first term is a signed projection of the changed physical superposition onto this pattern. The second changes magnitude everywhere even where there was no intersecting symbol. The statistic uses a symmetric affinity because either direction of a prior hard decision change may permit a different valid list. For each nonconstant binary output with unary score z, q_z(s)=exp(sz/2)/(2 cosh(z/2)), s=±1. Under the independent-output surrogate, the product affinity has log rho=sum[log cosh((z+z')/4)−0.5 log cosh(z/2)−0.5 log cosh(z'/2)]. The product-law TV distance is at most D=sqrt(1−rho²). D is a surrogate for changed hard-decoder outcomes, not a bound for the actual CRC/polar posterior or SCL list. Exclude all constant coordinates and assert this code has only its first coordinate constant. C uses z=2Ar/v,z'=2Ar0/v. D uses z=2Ar0/v,z'=2Ar0/v0. A zero change gets bottom priority; equal scores break on pattern ID. If the score is −infinity for all patterns (e.g. no change of count) use B then ID for those ties. Stable calculation uses logaddexp, −expm1 and clamps only positive floating roundoff in log affinity.

Conditional on additive independent equal-variance noise, folding removes every binary sign and preserves pattern-dependent amplitude information. For multiple remaining users the variance v is the existing decoder's Gaussian approximation and cancellation can also be wrong.
